# استراتژی استفاده از اینترنت بدون هزینه پولی

هدف: اپ بتواند از اینترنت برای بهتر شدن تجربه استفاده کند، اما هیچ API پولی یا سرور اجباری نداشته باشد.

## تصمیم پیشنهادی
برای نسخه اول، اپ همچنان Local-first باشد:
- داده‌های کاربر روی گوشی ذخیره شود.
- هسته برنامه‌ریزی، اولویت‌بندی و حسابداری داخل خود اپ اجرا شود.
- هیچ سرور اختصاصی لازم نباشد.
- هیچ API پولی مثل OpenAI، Google Cloud Speech paid، Azure، AWS و... استفاده نشود.

اما برای قابلیت صوتی، می‌توان از سرویس رایگان خود سیستم‌عامل استفاده کرد:
- Android: Speech Recognizer / Google Speech Service
- iOS: Apple Speech Recognition

این سرویس‌ها برای کاربر مستقیم هزینه API ندارند، ولی ممکن است برای دقت بهتر از اینترنت استفاده کنند.

## وضعیت فعلی کد
در `lib/screens/home_screen.dart` مقدار زیر تنظیم شده:

```dart
onDevice: false
```

یعنی اپ اجازه دارد از سرویس تشخیص گفتار گوشی استفاده کند؛ این معمولاً برای فارسی دقیق‌تر از حالت کاملاً آفلاین است و API پولی نمی‌خواهد.

اگر خواستی آفلاین‌تر شود:

```dart
onDevice: true
```

ولی دقت فارسی به گوشی کاربر وابسته می‌شود.

## چه چیزهایی رایگان می‌مانند؟
- Flutter: رایگان
- ذخیره‌سازی محلی: رایگان
- برنامه‌ریزی و اولویت‌بندی: رایگان
- حسابداری شخصی: رایگان
- فرمان صوتی با سرویس گوشی: بدون هزینه API
- خروجی Android: رایگان برای ساخت APK؛ انتشار در Google Play هزینه حساب توسعه‌دهنده دارد
- خروجی iOS: ساخت اپ نیاز به Mac/Xcode دارد؛ انتشار در App Store نیاز به حساب توسعه‌دهنده Apple دارد

## چیزهایی که فعلاً نباید استفاده کنیم چون ممکن است پولی شوند
- OpenAI API
- Google Cloud Speech-to-Text API
- Azure Speech
- AWS Transcribe
- Firebase paid features در حجم بالا
- سرور اختصاصی VPS

## اگر بعداً هوش مصنوعی آنلاین رایگان خواستی
می‌توان یک لایه اختیاری اضافه کرد:
- اگر کاربر API رایگان خودش را وارد کرد، استفاده شود.
- اگر quota تمام شد یا اینترنت نبود، اپ به موتور آفلاین Rule-Based برگردد.
- هیچ قابلیت اصلی وابسته به API پولی نباشد.

## پیشنهاد عملی برای MVP
1. فرمان صوتی با `speech_to_text` و `onDevice: false` برای دقت بهتر فارسی.
2. پردازش فرمان‌ها با `VoiceCommandProcessor` داخل اپ.
3. حسابداری و برنامه‌ریزی کاملاً محلی.
4. بعداً اگر لازم شد، Vosk/Whisper.cpp برای آفلاین کامل اضافه شود.
