# فاز ۱ اضافه شد

در این مرحله پروژه از نمونه اولیه ساده به نسخه کاربردی‌تر و حرفه‌ای‌تر نزدیک شد.

## ۱. دیتابیس واقعی

به جای ذخیره‌سازی ساده فقط با `shared_preferences`، ساختار SQLite اضافه شد.

فایل‌ها:
- `lib/services/database_service.dart`
- `lib/services/task_repository.dart`
- `lib/services/finance_repository.dart`

مزیت‌ها:
- آماده برای حجم زیاد کارها و تراکنش‌ها
- جستجو و گزارش‌گیری بهتر در مراحل بعد
- مهاجرت داده‌های قبلی از نسخه ساده به SQLite

## ۲. یادآوری و نوتیفیکیشن

سرویس نوتیفیکیشن محلی اضافه شد.

فایل:
- `lib/services/notification_service.dart`

رفتار فعلی:
- اگر کار مهلت انجام داشته باشد، یادآوری محلی ثبت می‌شود.
- اگر کار کامل یا حذف شود، یادآوری‌اش لغو می‌شود.
- نوتیفیکیشن پولی نیست و از قابلیت خود گوشی استفاده می‌کند.

## ۳. گزارش مالی بهتر

در بخش حسابدار اضافه شد:
- درآمد امروز
- هزینه امروز
- درآمد هفته جاری ایرانی
- هزینه هفته جاری ایرانی
- درآمد ماه شمسی
- هزینه ماه شمسی
- خالص ماه شمسی
- درآمد/هزینه بر اساس دسته‌بندی

## ۴. فرمان صوتی بهتر

پردازش فرمان فارسی بهتر شد:
- تشخیص «امروز»، «فردا»، «این هفته»
- تشخیص ساعت مثل «فردا ساعت پنج»
- تشخیص مبلغ‌های ایرانی مثل «سه میلیون تومان» یا «دویست هزار تومن»
- ساخت کار، ثبت درآمد، ثبت هزینه و تکمیل کار با صدا

## ۵. فارسی و ایرانی‌تر شدن رابط کاربری

اضافه شد:
- زبان برنامه: فارسی ایران
- اعداد فارسی
- تومان
- تاریخ شمسی
- مهلت انجام با ورودی شمسی
- هفته ایرانی با شروع شنبه برای گزارش مالی

## Permission های لازم بعد از ساخت پروژه Flutter

بعد از اجرای:

```bash
flutter create --platforms=android,ios .
```

### Android
در `android/app/src/main/AndroidManifest.xml`:

```xml
<uses-permission android:name="android.permission.RECORD_AUDIO" />
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.POST_NOTIFICATIONS" />
```

برای نوتیفیکیشن دقیق‌تر در اندرویدهای جدید ممکن است کاربر باید دسترسی «Alarms & reminders» را هم بدهد. نسخه فعلی از حالت inexact استفاده می‌کند تا حساسیت کمتری به این دسترسی داشته باشد.

### iOS
در `ios/Runner/Info.plist`:

```xml
<key>NSMicrophoneUsageDescription</key>
<string>برای دریافت فرمان صوتی فارسی به میکروفون نیاز داریم.</string>
<key>NSSpeechRecognitionUsageDescription</key>
<string>برای تبدیل گفتار فارسی به متن و اجرای فرمان‌ها استفاده می‌شود.</string>
```

## قدم‌های بعدی فاز ۱ که می‌توانیم کامل‌تر کنیم

- اضافه کردن فونت فارسی رایگان مثل Vazirmatn
- تقویم شمسی گرافیکی کامل
- خروجی CSV برای گزارش مالی
- صفحه تنظیمات برای انتخاب تومان/ریال
- هدف درآمدی ماهانه
- یادآوری شروع کار، نه فقط مهلت انجام
