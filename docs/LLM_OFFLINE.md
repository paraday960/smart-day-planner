# برنامه اضافه کردن LLM آفلاین واقعی

هدف: اپ بدون اینترنت بتواند مثل یک دستیار متنی فارسی، از روی کارهای کاربر پیشنهاد بدهد.

## واقعیت مهم
LLM آفلاین روی موبایل رایگان است، اما هزینه‌های فنی دارد:
- حجم مدل معمولاً از چندصد مگابایت تا چند گیگابایت است.
- روی گوشی‌های ضعیف کند می‌شود.
- باتری و RAM مصرف می‌کند.
- فارسی در مدل‌های خیلی کوچک ممکن است کیفیت متوسط داشته باشد.

برای همین در MVP فعلی از `RuleBasedLocalAssistant` استفاده شده تا اپ سبک و قابل اجرا باشد. اتصال LLM واقعی از طریق `LocalLlmAdapter` انجام می‌شود.

## مدل‌های پیشنهادی برای تست
- TinyLlama 1.1B Q4 — سبک، کیفیت فارسی محدود
- Qwen2.5 0.5B/1.5B Instruct Q4 — سبک‌تر و چندزبانه بهتر
- Phi کوچک quantized — خوب برای انگلیسی، فارسی بسته به نسخه

## مسیر پیاده‌سازی پیشنهادی
1. مدل quantized با فرمت GGUF آماده کن.
2. یک binding برای llama.cpp در Flutter اضافه کن.
3. کلاس جدید بساز:
   - `LlamaLocalAssistant implements LocalLlmAdapter`
4. prompt را کوتاه نگه دار و فقط اطلاعات لازم تسک‌ها را به مدل بده.
5. خروجی مدل را محدود کن: پیشنهاد بعدی، برنامه امروز، هشدار ریسک.

## نمونه prompt برای LLM
```
تو یک دستیار برنامه‌ریزی روزانه هستی. همه پاسخ‌ها فارسی، کوتاه و عملی باشند.
کارهای کاربر:
- عنوان: ...، اهمیت: ...، ددلاین: ...، زمان تخمینی: ...
سؤال کاربر: ...
خروجی: ۳ پیشنهاد عملی بده.
```

## سیاست حریم خصوصی
- هیچ داده‌ای به سرور ارسال نشود.
- همه تسک‌ها در حافظه محلی گوشی ذخیره شوند.
- اگر در آینده sync اضافه شد، opt-in و رمزنگاری‌شده باشد.
