# نقشه راه حرفه‌ای کردن Smart Day Planner

هدف نهایی: یک دستیار شخصی فارسی برای مدیریت زمان، کارها، درآمد، هزینه، هدف‌ها و تصمیم‌گیری روزانه؛ با کمترین هزینه و بدون وابستگی به API پولی.

---

## 1. تبدیل MVP به محصول قابل استفاده روزانه

### قابلیت‌های ضروری
- مدیریت کامل کارها: افزودن، ویرایش، حذف، تکمیل، تکرار، زیرکار، برچسب
- برنامه‌ریزی روزانه و هفتگی
- یادآوری و نوتیفیکیشن آفلاین
- ثبت زمان واقعی انجام کارها
- تحلیل عملکرد روزانه و هفتگی
- حسابداری شخصی: درآمد، هزینه، مانده، دسته‌بندی، گزارش ماهانه
- فرمان صوتی فارسی برای کارهای پرتکرار

### خروجی این فاز
اپ باید برای استفاده شخصی واقعی آماده باشد، حتی اگر هنوز خیلی هوشمند نباشد.

---

## 2. ارتقای دیتابیس و معماری

نسخه فعلی برای شروع از `shared_preferences` استفاده می‌کند. برای نسخه حرفه‌ای بهتر است به دیتابیس واقعی مهاجرت شود.

### پیشنهاد فنی
- دیتابیس: `Isar` یا `Drift/SQLite`
- مدیریت وضعیت: `Riverpod`
- معماری: Clean Architecture ساده‌شده
- لایه‌ها:
  - `models`
  - `repositories`
  - `services`
  - `controllers/providers`
  - `screens/widgets`

### چرا مهم است؟
با زیاد شدن کارها، تراکنش‌ها، تحلیل‌ها و گزارش‌ها، ذخیره‌سازی ساده کافی نیست.

---

## 3. هوشمندسازی واقعی بدون API پولی

### سطح 1: هوش قانون‌محور پیشرفته
- امتیازدهی اولویت با وزن‌های قابل تنظیم
- تشخیص کارهای فوری
- تشخیص کارهای درآمدزا
- پیشنهاد بهترین کار بعدی
- تحلیل عقب‌افتادگی
- تخمین زمان براساس سابقه کاربر

### سطح 2: مدل سبک محلی
- تخمین زمان انجام کار با ML کوچک
- پیش‌بینی درآمد احتمالی هر بازه کاری
- تشخیص الگوی بهره‌وری کاربر
- پیشنهاد بهترین ساعت برای کارهای سنگین

### سطح 3: LLM اختیاری
- مدل محلی مثل Qwen کوچک، TinyLlama، یا Vosk/Whisper برای صدا
- اگر کاربر خودش API رایگان داشت، اتصال اختیاری
- اگر اینترنت نبود، fallback به موتور داخلی

---

## 4. فرمان صوتی حرفه‌ای‌تر

### نسخه فعلی
کاربر دکمه میکروفون را نگه می‌دارد، حرف می‌زند، متن تشخیص داده می‌شود و فرمان اجرا می‌شود.

### ارتقاهای پیشنهادی
- تشخیص نیت کاربر: افزودن کار، ثبت درآمد، ثبت هزینه، تکمیل کار، پرسیدن برنامه
- استخراج موجودیت‌ها:
  - عنوان کار
  - زمان
  - تاریخ
  - مبلغ
  - دسته‌بندی
  - اهمیت
- تأیید قبل از عملیات حساس
- مثال:
  - «فردا ساعت پنج یادم بنداز با مشتری تماس بگیرم»
  - خروجی: ساخت تسک با ددلاین فردا ساعت ۵

### قابلیت خیلی مهم
اگر فرمان مبهم بود، اپ سؤال بپرسد:
- «منظورت کدام مشتری بود؟»
- «این مبلغ درآمد بود یا هزینه؟»

---

## 5. حسابدار حرفه‌ای شخصی

### امکانات پایه
- ثبت درآمد
- ثبت هزینه
- دسته‌بندی تراکنش‌ها
- گزارش روزانه، هفتگی، ماهانه
- درآمد خالص
- میانگین درآمد ساعتی

### امکانات حرفه‌ای
- بودجه‌بندی ماهانه
- هدف درآمدی روزانه/ماهانه
- هشدار خرج زیاد
- تحلیل اینکه کدام نوع کار سودآورتر است
- پیشنهاد تمرکز روی کارهای با درآمد ساعتی بالاتر
- گزارش مالی قابل خروجی گرفتن CSV/PDF

### ایده هوشمند
اپ بتواند بگوید:
«در هفته گذشته، کارهای طراحی سایت درآمد ساعتی بیشتری از تولید محتوا داشته‌اند. بهتر است فردا صبح ۲ ساعت برای طراحی سایت زمان بگذاری.»

---

## 6. اتصال زمان و پول

این بخش اپ را خاص و حرفه‌ای می‌کند.

### منطق پیشنهادی
برای هر کار، اپ بداند:
- چقدر زمان می‌برد
- آیا درآمدزا است؟
- درآمد احتمالی آن چقدر است؟
- انرژی لازم دارد یا نه؟
- ددلاین دارد یا نه؟

بعد پیشنهاد بدهد:
- کدام کار ارزش مالی بیشتری دارد
- کدام کار باید زودتر انجام شود
- آیا بهتر است یک کار کم‌درآمد حذف یا واگذار شود
- امروز چند ساعت کار لازم است تا به هدف درآمدی روزانه برسی

## 9. امنیت و حریم خصوصی

چون اطلاعات مالی و شخصی کاربر داخل اپ است، باید جدی گرفته شود.

### پیشنهادها
- قفل برنامه با PIN/اثر انگشت
- رمزنگاری بکاپ
- عدم ارسال داده به سرور بدون اجازه
- امکان حذف کامل داده‌ها
- خروجی گرفتن از داده‌ها

## 10. بکاپ و همگام‌سازی رایگان/کم‌هزینه

### بدون سرور اختصاصی
- خروجی/ورودی فایل JSON رمزنگاری‌شده
- بکاپ در حافظه گوشی
- اشتراک‌گذاری فایل بکاپ با Google Drive/iCloud توسط خود کاربر

### مرحله بعد
اگر بعداً خواستی sync واقعی بسازی:
- Supabase Free Tier
- Firebase Free Tier با احتیاط
- یا WebDAV/Google Drive API با اجازه کاربر

## تعریف نسخه حرفه‌ای نهایی

اپ وقتی حرفه‌ای محسوب می‌شود که بتواند به این سؤال‌ها جواب عملی بدهد:

- الان بهترین کاری که باید انجام بدهم چیست؟
- اگر امروز ۳ ساعت وقت دارم، چه برنامه‌ای بچینم؟
- کدام کارها بیشترین درآمد را برای زمان من دارند؟
- امروز چقدر درآمد داشتم؟
- برای رسیدن به هدف درآمد ماهانه، امروز چقدر باید کار کنم؟
- کدام هزینه‌ها زیاد شده‌اند؟
- کدام کارها عقب افتاده‌اند؟
- فردا بهتر است چه زمانی کارهای سنگین را انجام دهم؟

اگر این‌ها را خوب جواب بدهد، اپ واقعاً ارزشمند و متفاوت می‌شود.
