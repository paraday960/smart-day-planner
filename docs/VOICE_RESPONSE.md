# پاسخ صوتی فارسی دستیار

این قابلیت باعث می‌شود اپ فقط فرمان صوتی را نشنود، بلکه بعد از انجام کار با کاربر هم فارسی صحبت کند.

## امکانات اضافه‌شده

- پاسخ صوتی بعد از اجرای فرمان صوتی
- خواندن پاسخ دستیار بعد از سؤال متنی
- روشن/خاموش کردن پاسخ صوتی
- انتخاب بین دو حالت:
  - صدای زن
  - صدای مرد
- دکمه تست صدا
- زبان گفتار: فارسی ایران `fa-IR`

## فایل‌های مربوطه

- `lib/services/voice_response_service.dart`
- `lib/screens/home_screen.dart`
- `pubspec.yaml`

## پکیج استفاده‌شده

```yaml
flutter_tts: ^4.0.2
```

این پکیج از موتور Text-to-Speech خود گوشی استفاده می‌کند:

- Android: موتور گفتار اندروید، معمولاً Google Text-to-Speech یا موتور نصب‌شده توسط کاربر
- iOS: Apple Speech Synthesis

## نکته مهم درباره صدای زن و مرد بدون لهجه

در نسخه رایگان و بدون API پولی، کیفیت و تعداد صداها به گوشی کاربر بستگی دارد. برنامه تلاش می‌کند صدای فارسی زن یا مرد را پیدا کند، اما تضمین صددرصدی برای وجود هر دو صدا روی همه گوشی‌ها وجود ندارد.

برای بهترین تجربه در ایران:

### Android
کاربر بهتر است این موارد را بررسی کند:

1. تنظیمات گوشی
2. Language & Input
3. Text-to-Speech output
4. انتخاب Google Speech Services یا موتور فارسی مناسب
5. نصب/فعال‌کردن زبان فارسی

### iOS
کیفیت صدا به صداهای فارسی موجود در iOS بستگی دارد.

## اگر صدای کاملاً ثابت و حرفه‌ای بخواهیم

برای اینکه اپ روی همه گوشی‌ها دقیقاً دو صدای مشخص، جذاب و بی‌لهجه داشته باشد، باید یکی از این مسیرها را اضافه کنیم:

### مسیر رایگان/محلی
- استفاده از مدل TTS فارسی آفلاین
- حجم برنامه بیشتر می‌شود
- پیاده‌سازی سخت‌تر است
- ولی هزینه API ندارد

### مسیر اینترنتی ولی بدون هزینه اجباری
- استفاده اختیاری از سرویس‌های رایگان یا کلید API خود کاربر
- اگر سرویس در دسترس نبود، اپ به صدای سیستم گوشی برگردد

### مسیر پولی، که فعلاً نمی‌خواهیم
- سرویس‌های Neural TTS پولی مثل Google Cloud، Azure، ElevenLabs و مشابه آن‌ها

## رفتار فعلی برنامه

وقتی کاربر بگوید:

```text
درآمد سه میلیون ثبت کن
```

اپ هم عملیات را انجام می‌دهد، هم با صدای انتخاب‌شده جواب می‌دهد:

```text
درآمد ۳٬۰۰۰٬۰۰۰ تومان ثبت شد و به درآمد فعلی اضافه شد.
```

## پیشنهاد برای مرحله بعد

- اضافه کردن تنظیم سرعت صدا
- اضافه کردن تنظیم زیر و بمی صدا
- اضافه کردن گزینه «فقط در فرمان صوتی صحبت کن»
- اضافه کردن موتور گفتار فارسی محلی برای صدای ثابت‌تر
