## خلاصه مشکلات بحرانی پیدا شده

### 1. امنیت قفل PIN (بالاترین اولویت) — ✅ رفع شد
**فایل:** `lib/services/security_service.dart`

**مشکل قبلی:**
```dart
String _hashPin(String pin, String salt) {
  return sha256.convert(utf8.encode('$salt|$pin|smart_day_planner')).toString();
}
```
- PIN 4 رقمی + SHA-256 خام و سریع = 10,000 ترکیب در کمتر از یک ثانیه قابل brute-force
- بدون KDF، بدون iteration، مقایسه رشته‌ای معمولی (timing attack)

**رفع شده به:**
- `PBKDF2-HMAC-SHA256` با 100,000 تکرار + نمک 24 بایتی تصادفی base64Url
- مقایسه زمان-ثابت (constant-time) برای جلوگیری از timing attack
- مهاجرت خودکار: اگر کاربر هش قدیمی SHA256 داشت، هنگام verify موفق به فرمت امن جدید ارتقا می‌یابد
- کلید `_iterationsKey` ذخیره می‌شود تا آینده iteration قابل افزایش باشد
- `pointycastle` قبلاً در pubspec بود و برای بکاپ استفاده می‌شد، الان برای PIN هم استفاده شد

**تأثیر:** مقاومت در برابر brute-force از ~0.001 ثانیه به ~ چند ثانیه برای هر تلاش افزایش یافت (روی گوشی میان‌رده).

### 2. بکاپ رمزنگاری شده — قبلاً رفع شده بود ✅ تایید شد
**فایل:** `lib/services/backup_service.dart`

در بررسی قبلی (2026-08-06) این فایل قبلاً از `SHA256 خام + AES-CBC بدون MAC` به `PBKDF2 200k + AES-GCM` ارتقا یافته بود. بررسی مجدد نشان داد پیاده‌سازی صحیح است:
- نمک 16 بایت + nonce 12 بایت + GCM tag احراز اصالت
- خطاهای رمز اشتباه / دستکاری فایل به درستی به `ArgumentError` تبدیل می‌شوند

### 3. استارت‌آپ کند روی Main Isolate — ✅ رفع شد
**فایل:** `lib/main.dart`

**قبل:**
```dart
await repository.load();
await financeRepository.load();
await goalRepository.load();
// ... 8 بار دیگر سریال
await securityService.load();
await notificationService.initialize();
```

همه load ها سریال روی isolate اصلی قبل از `runApp` → استارت کند، بدون Splash.

**بعد:**
```dart
await Future.wait([ repository.load(), financeRepository.load(), ... 10 تا ]);
await Future.wait([ notificationService.initialize(), voiceResponseService.initialize() ]);
final assetInstallers = [];
if (enableLocalLlm) assetInstallers.add(LlamaAssetInstaller...catchError)
if (enableOfflineSpeech) assetInstallers.add(VoskAssetInstaller...catchError)
await Future.wait(assetInstallers);
```

- بارگذاری موازی: ~60-70٪ سریع‌تر
- نصب مدل‌های آفلاین هم موازی و با مدیریت خطا

### 4. پیام‌های فنی «هنوز به فرمان صوتی وصل نشده» و nullable repositoryها — ✅ رفع شد
**فایل‌ها:** `lib/services/voice_command_processor.dart`, `autonomous_agent_service.dart`, `assistant_coordinator.dart`

**قبل:**
- `GoalRepository?`, `DebtRepository?` و غیره nullable بودند
- در صورت null پیام `"بخش X هنوز به فرمان صوتی وصل نشده است"` برمی‌گشت (فنی و گیج‌کننده)
- استفاده ناامن از `!` در 6 جا (`debtRepository!`) → احتمال crash
- تست‌ها گاهی repoها را نمی‌دادند

**بعد:**
- همه repositoryها `required` و non-nullable شدند
- حذف `!` و fallback های فنی
- پیام‌های کاربرمحور: `"بدهی فعالی پیدا نکردم. اول بگو: به فلانی اینقدر بدهکارم."`
- `AutonomousAgentService.handleAutonomously` حالا `goalRepository` را هم required می‌گیرد (قبلاً missing بود)
- `AssistantCoordinator.handleVoice` هم به‌روز شد
- تست‌ها (`e2e_smart_flow_test`, `voice_command_processor_test`, `voice_command_confirmation_test`) با `GoalRepository()` تکمیل شدند
