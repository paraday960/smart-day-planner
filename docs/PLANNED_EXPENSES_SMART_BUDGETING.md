# برنامه‌ریزی هوشمند هزینه‌های آینده

این قابلیت برای سناریوهایی مثل این ساخته شده است:

> هفته دیگه می‌خوام با دوست‌دخترم برم بیرون و این کار یک میلیون خرج داره.

برنامه باید این را بفهمد و انجام دهد:

1. یک «هزینه آینده» ثبت کند.
2. مبلغ موردنیاز را ذخیره کند.
3. تاریخ هدف را تشخیص دهد.
4. محاسبه کند تا آن تاریخ روزانه چقدر باید درآمد داشته باشی.
5. اگر امروز کمتر درآمد داشتی، روزهای بعدی را با باقی‌مانده جدید دوباره محاسبه کند.

## فرمان‌های صوتی/متنی نمونه

```text
هفته دیگه می‌خوام با دوست دخترم برم بیرون و این کار یک میلیون تومان خرج داره
```

```text
هفته بعد میخوام سفر برم و پنج میلیون هزینه داره
```

```text
برنامه هزینه تولد، دو میلیون تومان، برای هفته بعد
```

## منطق محاسبه

برای هر هزینه آینده:

```text
باقی‌مانده = مبلغ هدف - درآمد ثبت‌شده از زمان ایجاد هدف
روزهای باقی‌مانده = تعداد روز تا تاریخ هدف
درآمد لازم روزانه = باقی‌مانده / روزهای باقی‌مانده
زمان کار لازم روزانه = درآمد لازم روزانه / میانگین درآمد ساعتی
```

اگر یک روز کمتر درآمد داشته باشی، چون «باقی‌مانده» کم‌تر از انتظار کاهش پیدا نکرده، روز بعد درآمد لازم روزانه بیشتر می‌شود.

## مثال

فرض کن:

```text
هزینه آینده: بیرون رفتن
مبلغ: ۱٬۰۰۰٬۰۰۰ تومان
زمان: ۷ روز دیگر
```

روز اول برنامه می‌گوید:

```text
روزانه حدود ۱۴۳٬۰۰۰ تومان لازم داری.
```

اگر روز اول فقط ۵۰٬۰۰۰ تومان درآمد ثبت کنی، روز بعد برنامه دوباره حساب می‌کند:

```text
باقی‌مانده: ۹۵۰٬۰۰۰ تومان
روزهای باقی‌مانده: ۶
روزانه لازم: حدود ۱۵۹٬۰۰۰ تومان
```

یعنی کم‌کاری روز قبل در محاسبات روزهای بعد لحاظ می‌شود.

## نمایش در برنامه

در تب «حسابدار» بخش جدید اضافه شده:

```text
هزینه‌های آینده
```

در داشبورد امروز هم بخش زیر اضافه شده:

```text
برنامه‌ریزی هزینه‌های آینده
```
