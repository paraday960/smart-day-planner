# فاز ۷ اضافه شد — اعتمادسنجی، تأیید عملیات حساس و نمودارهای هوشمند

فاز ۷ روی قابل اعتمادتر شدن دستیار تمرکز دارد. در عملیات مالی، اشتباه کوچک می‌تواند باعث ثبت داده غلط شود؛ برای همین برنامه باید میزان اطمینان خود را بسنجد و در موارد حساس تأیید بگیرد.

---

## ۱. سیستم اعتمادسنجی فرمان‌ها

سرویس جدید:

```text
lib/services/command_confidence_service.dart
```

این سرویس برای فرمان‌های مالی یک امتیاز اطمینان محاسبه می‌کند.

مواردی که بررسی می‌شود:

- آیا مبلغ مشخص است؟
- آیا واحد پول واضح است؟
- آیا نوع عملیات مشخص است؟
- آیا شخص یا تاریخ لازم مشخص شده؟
- آیا مبلغ بزرگ است؟
- آیا عبارت محاوره‌ای مبهم مثل «پونصد» استفاده شده؟

---

## ۲. تأیید قبل از عملیات حساس مالی

اگر اطمینان پایین باشد یا مبلغ بزرگ باشد، برنامه مستقیم اجرا نمی‌کند.

مثال:

```text
هزینه یک میلیون ثبت کن
```

برنامه می‌پرسد:

```text
برای اطمینان، هزینه ۱٬۰۰۰٬۰۰۰ تومان ثبت شود؟ بگو تأیید یا لغو.
```

اگر بگویی:

```text
تأیید
```

عملیات انجام می‌شود.

اگر بگویی:

```text
لغو
```

عملیات انجام نمی‌شود.

---

## ۳. تأیید برای بدهی و هزینه آینده

برای ثبت بدهی و هزینه آینده، اگر مبلغ بالا باشد یا جمله کمی مبهم باشد، برنامه تأیید می‌گیرد.

مثال:

```text
به ممد یک میلیون بدهکارم تا دو روز دیگه باید پس بدم
```

برنامه ممکن است بپرسد:

```text
برای اطمینان، بدهی ممد به مبلغ ۱٬۰۰۰٬۰۰۰ تومان با مهلت ... ثبت شود؟
```

## ۴. نمودارهای هوشمند مالی

سرویس جدید:

```text
lib/services/chart_insight_service.dart
```

در تب حسابدار اضافه شد:

- نمودار درآمد و هزینه ۷ روز اخیر
- نمودار سهم هزینه‌های ماه شمسی بر اساس دسته‌بندی

این نمودارها بدون پکیج اضافه و با ویجت‌های سبک Flutter ساخته شده‌اند.
